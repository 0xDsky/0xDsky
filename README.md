## 🔧 What I build

### [mend](https://github.com/0xDsky/Mend)
One patch tool for every AI edit format — unified diff, SEARCH/REPLACE blocks, V4A patches, JSON tool calls. Reads them all to one spec, finds the lines even when the model drifted whitespace, and changes every file or none (atomic). Zero dependencies, Node 22 stdlib only. Built for make.fun's `hidden-spec-cli` bounty.

### [bsc-mint-tools](https://github.com/0xDsky/Bsc-mint-tools)
Two small read-only CLI tools for BSC free-mint hunters. `claim-check` lists which of your NFTs can claim tokens right now; `radar` lists the newest BSC tokens and scores each by market signal. No keys, no signing, no transactions.
